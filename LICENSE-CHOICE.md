# Elige una licencia antes de publicar

No hay una licencia incluida por defecto. Esa decisión pertenece a la persona propietaria del código.

Antes de hacer público el repositorio, añade una licencia que refleje los permisos que deseas conceder. Si no añades ninguna, GitHub mostrará el código, pero otras personas no recibirán permisos legales amplios para reutilizarlo, modificarlo o redistribuirlo.
